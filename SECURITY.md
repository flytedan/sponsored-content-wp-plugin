# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Flytedesk Sponsored Content, please report it privately - **do not open a public GitHub issue**.

Email **security@flytedesk.com** with:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it (a minimal request/payload is ideal, since this plugin's attack surface is almost entirely its REST API).
- The plugin version, WordPress version, and PHP version you tested against.

We aim to acknowledge new reports within 2 business days and to keep you updated as a fix is developed. Please allow us a reasonable amount of time to investigate and patch a confirmed issue before any public disclosure.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

Only the latest `1.x` release is actively supported with security fixes.
